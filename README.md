# AgriSmart 2.0

AI-powered smart farming platform.

## Architecture

- Backend: Python + FastAPI
- AI/ML: Python, scikit-learn, TensorFlow/PyTorch
- Mobile: Flutter + Dart
- Database: PostgreSQL + SQL
- Admin web: React + TypeScript

## Core modules

1. Crop Recommendation
2. Plant Disease Detection
3. Yield Prediction
4. AgriBot AI Assistant
5. Smart Farming Decision Engine
6. Weather & Farm Monitoring
